Random Password Generator

Project Description

The Random Password Generator is a Python-based application that generates secure random passwords based on user preferences. Users can select the password length and choose whether to include uppercase letters, lowercase letters, numbers, and special symbols.

Features

- Generates random passwords.
- Allows users to choose password length (minimum 8 characters).
- Includes uppercase letters (A–Z).
- Includes lowercase letters (a–z).
- Includes numbers (0–9).
- Includes special symbols.
- Uses Python's secrets module for secure random generation.
- Displays the generated password and its length.

Technologies Used

- Python 3
- string module
- secrets module

How to Run

1. Install Python 3.
2. Download or clone this project.
3. Open the project folder.
4. Run the following command:

python random_password_generator.py

Sample Input

- Password Length: 12
- Uppercase: Yes
- Lowercase: Yes
- Numbers: Yes
- Symbols: Yes

Sample Output

=== Random Password Generator ===

Generated Password: aB7@kP2#mN9!
Password Length: 12

Note: The generated password will be different each time.
