#BMI Calculator

##Project Description
This is a beginner-level Python project that calculates Body Mass Index (BMI) using a person's weight and height.

##Features
-Accepts the user's name
-Accepts weight in kilograms
-Accepts height in metres
-Calculates BMI
-Displays a BMI category
-Checks for zero or negative height and weight
 
##Technology used
-Python 3

##How to Run
1. Install Python 3
2. Open a terminal in the project folder
3. Run: python bmi_calculator.py 
4. Enter the requested details

##Sample Input
Name: Vivian
Weight: 55 kg
Height: 1.60 m

##Expected Result 
BMI: approximately 21.48
Category: Normal range
